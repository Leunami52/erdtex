+++
id = "ER-30"
title = "A generalisation's supertype must be an entity type"
kind = "error"
applies = ["IS_A", "CAN_BE", "entity type"]
see = ["ER-29", "ER-7", "DRAW-6"]
+++
**Rule.** The supertype of a generalisation (IS_A or CAN_BE) **must** be an entity type (weak or not).

**What the program does.** An error, *"the supertype 'x' is not an entity"*, when it names a
relationship type, a PART_OF, a Chen attribute, a junction point or another generalisation.

**Why.** A generalisation relates sets of entities: every subtype entity is an entity of the supertype.
A relationship or an attribute isn't a set of entities.

**Examples.**

```erd violates ER-30
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*SSN, Name}
\relationship{works}(5,0){works}
\link{person}{works}{cn}
\isa{g}(5,-2.5){works}{cd}
\entity{employee}(5,-5){Employee}
\link{employee}{g}
```

```erd follows
\entity{person}(0,0){Person}
\attributes{person}{*SSN, Name}
\isa{g}(0,-2){person}{cd}
\entity{employee}(-2,-4){Employee}
\entity{student}(2,-4){Student}
\link{employee}{g}
\link{student}{g}
```
