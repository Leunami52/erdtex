id = "ER-21"
title = "The line from a weak relationship type to its weak entity type is double"
kind = "warning"
applies = ["line", "weak relationship type", "weak entity type"]
fix = "Make double-lined"
see = ["ER-22", "ER-23"]
+++
**Rule.** The line between a weak relationship type and the weak entity type that depends through it
**should** be double.

**What the program does.** A warning, *"a link between a weak relationship and a weak entity should be
double-lined"*, with the fix *Make double-lined*. The program draws such a line double itself when it is
created; older files get the warning.

- It applies where the weak relationship type has exactly one weak entity type. Where it joins two weak
  entity types, only the dependent one's line is double, and the program can't know which that is: ER-23
  asks instead.
- A weak entity type that depends on itself (ER-25) has both its lines to the relationship double: both
  lead to the weak entity type.

**Why.** The double line shows at a glance which entity type depends, and through which relationship;
the relational schema and the dashed underline of the weak entity type's key follow it.

**Examples.**

```erd violates ER-21
\entity{building}(0,0){Building}
\attributes[anchor=west]{building}{*Name}
\relationship[dependency=Id]{contains}(4,0){contains}
\entity[weak]{room}(8,0){Room}
\attributes{room}{*Number}
\link{building}{contains}{1}
\link{contains}{room}{n}
```

```erd follows
\entity{building}(0,0){Building}
\attributes[anchor=west]{building}{*Name}
\relationship[dependency=Id]{contains}(4,0){contains}
\entity[weak]{room}(8,0){Room}
\attributes{room}{*Number}
\link{building}{contains}{1}
\link[double]{contains}{room}{n}
```
