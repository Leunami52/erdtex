+++
id = "ER-31"
title = "A generalisation should have subtypes"
kind = "warning"
applies = ["IS_A", "CAN_BE"]
see = ["ER-7"]
+++
**Rule.** A generalisation (IS_A or CAN_BE) **should** have at least one subtype linked to it by a line.

**What the program does.** A warning, *"this generalisation has no subtypes linked to it"*, when no line
at all leads to it.

- Any line counts here, also one that breaks ER-7.
- One subtype is enough for this rule; a complete generalisation with a single subtype is unusual, but
  allowed.

**Why.** A generalisation without subtypes specialises nothing; it is usually left over from editing.

**Examples.**

```erd violates ER-31
\entity{person}(0,0){Person}
\attributes{person}{*SSN, Name}
\isa{g}(0,-2){person}{cd}
```

```erd follows
\entity{person}(0,0){Person}
\attributes{person}{*SSN, Name}
\isa{g}(0,-2){person}{cd}
\entity{employee}(-2,-4){Employee}
\entity{student}(2,-4){Student}
\link{employee}{g}
\link{student}{g}
```
