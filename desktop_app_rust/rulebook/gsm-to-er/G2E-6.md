+++
id = "G2E-6"
title = "A multi-valued attribute line to an object type becomes a relationship cn:cn"
kind = "conversion"
applies = ["multi-valued attribute line", "abstract type", "relationship type"]
see = ["G2E-4", "G2E-7"]
+++
**Rule.** A multi-valued attribute line from an object type to another object type **becomes** a
relationship type named after the line's label, with `cn` at both ends.

**Conditions.** As for single-valued lines (G2E-4): *has* without a label; a recursive relationship for a
line from a type to itself; two lines in opposite directions are G2E-7.

**Why.** Each source object refers to any number of target objects, and nothing says how many sources a
target has: `cn` at both ends, in n-notation.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\abstract{course}(5,0){Course}
\multiattribute{person}{course}{attends}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{attends}(3.2,0){attends}
\entity{course}(6.5,0){Course}
\attributes{course}{*Course ID}
\link{person}{attends}{cn}
\link{attends}{course}{cn}
```
