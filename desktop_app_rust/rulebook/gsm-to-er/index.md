How *File → Convert to ER Diagram…* turns a GSM diagram into an ER diagram. The GSM diagram itself
is never changed: the result opens as a new, unsaved ER diagram.

In these rules, **becomes** says what an element turns into. Where a conversion could go more than one
way, the rule names the **choices** the conversion dialog offers, and which one it takes unless you
choose another.
