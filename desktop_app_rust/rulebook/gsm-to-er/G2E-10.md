title = "An aggregation of values, and every other aggregation"
kind = "conversion"
applies = ["aggregation", "component line", "entity type", "attribute"]
see = ["G2E-9", "G2E-4"]
+++
**Rule.** An aggregation of representable types only, referred to by exactly one single-valued attribute
line from an object type, **becomes**, by default, an entity type linked to that object type; or, if
chosen, a composite attribute of it. Every other aggregation (not covered by G2E-9) **becomes** an entity
type.

**Conditions.**

- As an entity type: its representable components become its attributes (one that names an identifier
  becomes the key, otherwise one is added, G2E-2); each object component becomes a relationship, named
  after the component line's label or *has*, with `cn` at the aggregation and `1` at the component; a
  grouping component becomes a relationship to its member type (G2E-8). Attribute lines to it become
  relationships to it (G2E-4).
- As a composite attribute: named after the aggregation, its parts named after its representable
  components (*Address{Street, Town}*).

**Choices.** *Aggregation ‹name›* in the conversion dialog, for an aggregation of values used once:
*Entity type* (the default) or *Composite attribute*.

**Why.** A combination of values used by one object type is a part of its description: a composite
attribute says so most directly. As an entity type it can carry a key and be referred to; an aggregation
used by several object types needs that.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\aggregation{addr}(4,0){Address}
\representable{street}(8,1){Street}
\representable{town}(8,-1){Town}
\component{addr}{street}
\component{addr}{town}
\attribute{person}{addr}{lives at}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{lives_at}(2.6,0){lives at}
\entity{addr}(5.2,0){Address}
\attributes{addr}{*Address ID, Street, Town}
\link{person}{lives_at}{cn}
\link{lives_at}{addr}{1}
```

```gsmd converts pick=composite
\abstract{person}(0,0){Person}
\aggregation{addr}(4,0){Address}
\representable{street}(8,1){Street}
\representable{town}(8,-1){Town}
\component{addr}{street}
\component{addr}{town}
\attribute{person}{addr}{lives at}
```

```erd result
\entity{person}(0,0){Person}
\attributes{person}{*Person ID, Address{Street, Town}}
```
