+++
id = "G2E-7"
title = "Two attribute lines in opposite directions"
kind = "conversion"
applies = ["attribute line", "multi-valued attribute line", "relationship type"]
see = ["G2E-4", "G2E-6"]
+++
**Rule.** Two attribute lines between the same two object types in opposite directions (*Person lives
in City*, *City home of Person*) **become**, by default, one relationship whose cardinalities come from
both lines; or, if chosen, two relationships.

**Conditions.**

- One relationship: named after the first line's label (in the file's order); each line's kind gives the
  cardinality at its target: `1` for single-valued, `cn` for multi-valued.
- Two relationships: each line becomes a relationship of its own, as any line between object types does.
- It applies only where there is exactly one line in each direction between two different types. The
  question is asked once for the pair, about the line first in the file.

**Choices.** *‹A› ‹label› / ‹B› ‹label›* in the conversion dialog: *One relationship (inverse
attributes)* (the default) or *Two relationships*.

**Why.** Often the two lines say the same fact from both sides: each person lives in one city, so each
city is home of many people. One relationship then says it once, with both cardinalities. If they are
different facts (a person *works in* a city, a city is *home of* people), two relationships are right.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\abstract{city}(5,0){City}
\attribute[bend left=25]{person}{city}{lives in}
\multiattribute[bend left=25]{city}{person}{home of}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{lives_in}(3.2,0){lives in}
\entity{city}(6.5,0){City}
\attributes{city}{*City ID}
\link{person}{lives_in}{cn}
\link{lives_in}{city}{1}
```

```gsmd converts pick=separate
\abstract{person}(0,0){Person}
\abstract{city}(5,0){City}
\attribute[bend left=25]{person}{city}{lives in}
\multiattribute[bend left=25]{city}{person}{home of}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{lives_in}(3.2,-1){lives in}
\relationship{home_of}(3.2,1){home of}
\entity{city}(6.5,0){City}
\attributes{city}{*City ID}
\link{person}{lives_in}{cn}
\link{lives_in}{city}{1}
\link{city}{home_of}{cn}
\link{home_of}{person}{cn}
```
