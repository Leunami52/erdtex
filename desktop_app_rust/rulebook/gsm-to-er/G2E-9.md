+++
id = "G2E-9"
title = "An aggregation of object types that nothing refers to"
kind = "conversion"
applies = ["aggregation", "component line", "relationship type", "entity type"]
see = ["G2E-10", "G2E-11"]
+++
**Rule.** An aggregation with at least two object types among its components, which nothing refers to,
**becomes**, by default, a relationship type between its components; or, if chosen, an entity type with a
relationship to each of them.

**Conditions.**

- As a relationship: named after the aggregation, `cn` at each component; a component line's label
  becomes the role of its line; representable components and the aggregation's own attribute lines to
  representable types become attributes of the relationship.
- As an entity type: named after the aggregation, with a key by G2E-2, and a relationship *has* (or the
  component line's label) to each object component, `cn` at the aggregation and `1` at the component.
- Object components are abstract types, subtypes, aggregations and groupings.

**Choices.** *Aggregation ‹name› (‹parts›)* in the conversion dialog: *Relationship type* (the default)
or *Entity type*.

**Why.** An aggregation of objects is what a relationship type is in ER: a combination of entities,
possibly with attributes of its own. If the combination needs to be referred to later, or is a thing of
its own, an entity type is the better fit.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\abstract{company}(8,0){Company}
\aggregation{works}(4,0){Employment}
\component{works}{person}
\component{works}{company}
\representable{year}(4,3){Year}
\attribute{works}{year}{since}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{employment}(6,0){Employment}
\attributes[anchor=north]{employment}{Year}
\entity{company}(12,0){Company}
\attributes{company}{*Company ID}
\link{person}{employment}{cn}
\link{employment}{company}{cn}
```

```gsmd converts pick=entity
\abstract{person}(0,0){Person}
\abstract{company}(8,0){Company}
\aggregation{works}(4,0){Employment}
\component{works}{person}
\component{works}{company}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{has}(3.5,0){has}
\entity{works}(7,0){Employment}
\attributes[anchor=north]{works}{*Employment ID}
\relationship{has2}(12,0){has}
\entity{company}(15.5,0){Company}
\attributes{company}{*Company ID}
\link{person}{has}{1}
\link{has}{works}{cn}
\link{works}{has2}{cn}
\link{has2}{company}{1}
```
