+++
id = "ER-29"
title = "A generalisation's supertype must exist"
kind = "error"
applies = ["IS_A", "CAN_BE"]
see = ["ER-30"]
+++
**Rule.** The supertype a generalisation (IS_A or CAN_BE) names **must** be an element of the diagram.

**What the program does.** An error, *"the supertype 'x' does not exist"*, at the generalisation.

- The supertype is the generalisation's own field (*Supertype* in its *Element* pane;
  `\isa{g}(x,y){supertype}{cd}` in the file), not a line.
- An anchor (`person.south`) counts as its element.
- The program places a generalisation by clicking its supertype, and deletes it with its supertype; so
  this happens in a file written or changed by hand.

**Why.** A generalisation says which entity type its subtypes specialise; without it, it says nothing.

**Examples.**

```erd violates ER-29
\isa{g}(0,-2){person}{cd}
\entity{employee}(-2,-4){Employee}
\entity{student}(2,-4){Student}
\link{employee}{g}
\link{student}{g}
```

```erd follows
\entity{person}(0,0){Person}
\attributes{person}{*SSN, Name}
\isa{g}(0,-2){person}{cd}
\entity{employee}(-2,-4){Employee}
\entity{student}(2,-4){Student}
\link{employee}{g}
\link{student}{g}
```
