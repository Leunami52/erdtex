+++
id = "ER-20"
title = "A weak relationship type should connect a weak entity type"
kind = "warning"
applies = ["weak relationship type", "weak entity type"]
see = ["ER-19"]
+++
**Rule.** A relationship type marked weak, or with a dependency (E or Id), **should** be linked to at
least one weak entity type: the one that depends on the other side.

**What the program does.** A warning, *"a weak/dependency relationship should connect a weak entity"*,
when the relationship type has lines but none of them leads to a weak entity type.

- A weak relationship type without any line gets no such warning (it gets ER-8).

**Why.** A weak relationship type says that one side depends on the other; that side is a weak entity
type by definition. If none of its entity types is weak, either the relationship isn't weak or an entity
type hasn't been marked weak.

**Examples.**

```erd violates ER-20
\entity{building}(0,0){Building}
\attributes[anchor=west]{building}{*Name}
\relationship[dependency=Id]{contains}(4,0){contains}
\entity{room}(8,0){Room}
\attributes{room}{*Number}
\link{building}{contains}{1}
\link{contains}{room}{n}
```

```erd follows
\entity{building}(0,0){Building}
\attributes[anchor=west]{building}{*Name}
\relationship[dependency=Id]{contains}(4,0){contains}
\entity[weak]{room}(8,0){Room}
\attributes{room}{*Number}
\link{building}{contains}{1}
\link[double]{contains}{room}{n}
```
