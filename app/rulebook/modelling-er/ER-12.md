+++
id = "ER-12"
title = "A cardinality belongs on a line to an entity type"
kind = "warning"
applies = ["line"]
see = ["ER-11"]
+++
**Rule.** A cardinality **should** stand only on a line with an entity type at one end.

**What the program does.** A warning, *"the cardinality 'x' is on an edge without an entity"*, at a
labelled line neither of whose ends is an entity type: between a relationship type and a Chen attribute,
for instance.

- The label's text doesn't matter: any label on such a line is reported.
- A line with an entity type at one end isn't reported, even where a label means nothing (such as on a
  line to a generalisation).

**Why.** A cardinality counts how often an entity takes part in a relationship. Where no entity type is
at the line, there is nothing it could count.

**Examples.**

```erd violates ER-12
\entity{student}(0,0){Student}
\attributes[anchor=west]{student}{*Student Id}
\relationship{attends}(4,0){attends}
\entity{course}(8,0){Course}
\attributes{course}{*Course Id}
\attribute{since}(4,2.5){Since}
\link{student}{attends}{cn}
\link{attends}{course}{cn}
\link{attends}{since}{1}
```

```erd follows
\entity{student}(0,0){Student}
\attributes[anchor=west]{student}{*Student Id}
\relationship{attends}(4,0){attends}
\entity{course}(8,0){Course}
\attributes{course}{*Course Id}
\attribute{since}(4,2.5){Since}
\link{student}{attends}{cn}
\link{attends}{course}{cn}
\link{attends}{since}
```
