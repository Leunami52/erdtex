+++
id = "ER-22"
title = "Only the line from a weak relationship type to a weak entity type may be double"
kind = "error"
applies = ["line"]
fix = "Make single-lined"
see = ["ER-21"]
+++
**Rule.** A line **must not** be double unless it joins a weak relationship type and a weak entity type.

**What the program does.** An error, *"only a link between a weak relationship and a weak entity can be
double-lined"*, with the fix *Make single-lined*.

- The owner's line of a weak relationship type is single: its entity type isn't weak.
- Between two weak entity types, both lines *may* be double as far as this rule goes; but exactly one
  should be (ER-23).
- Lines in GSM diagrams are never double.

**Why.** The double line means "depends through this relationship". Anywhere else it means nothing, and
it would mislead.

**Examples.**

```erd violates ER-22
\entity{student}(0,0){Student}
\attributes[anchor=west]{student}{*Student Id}
\relationship{attends}(4,0){attends}
\entity{course}(8,0){Course}
\attributes{course}{*Course Id}
\link[double]{student}{attends}{cn}
\link{attends}{course}{cn}
```

```erd violates ER-22
\entity{building}(0,0){Building}
\attributes[anchor=west]{building}{*Name}
\relationship[dependency=Id]{contains}(4,0){contains}
\entity[weak]{room}(8,0){Room}
\attributes{room}{*Number}
\link[double]{building}{contains}{1}
\link[double]{contains}{room}{n}
```

```erd follows
\entity{building}(0,0){Building}
\attributes[anchor=west]{building}{*Name}
\relationship[dependency=Id]{contains}(4,0){contains}
\entity[weak]{room}(8,0){Room}
\attributes{room}{*Number}
\link{building}{contains}{1}
\link[double]{contains}{room}{n}
```
