+++
id = "ER-27"
title = "Depending on itself, the topmost one needs none above it"
kind = "warning"
applies = ["weak relationship type", "weak entity type", "line"]
see = ["ER-26", "ER-28"]
+++
**Rule.** In an existence dependency of an entity type on itself, the owner's end **should** allow none:
`c` (n-notation) or `(0,1)` (min-max), not `1` or `(1,1)`.

**What the program does.** A warning, *"every 'Chapter' needs a 'whole' here, so there can't be a topmost
'Chapter'; allow none at that end (c, or (0,1))"*. Where the owner's end has no role, the message says
*"a 'Chapter' above it"* instead of the role.

**Why.** If every chapter had to be within another chapter, the chain upwards would never end: there
couldn't be a first chapter, so there couldn't be any chapters at all.

**Examples.**

```erd violates ER-27
\entity[weak]{chapter}(0,0){Chapter}
\attributes[anchor=west]{chapter}{*Title}
\relationship[dependency=E]{in}(5,0){in}
\link[role=part, double, bend left=30]{chapter}{in}{cn}
\link[role=whole, double, bend right=30]{chapter}{in}{1}
```

```erd follows
\entity[weak]{chapter}(0,0){Chapter}
\attributes[anchor=west]{chapter}{*Title}
\relationship[dependency=E]{in}(5,0){in}
\link[role=part, double, bend left=30]{chapter}{in}{cn}
\link[role=whole, double, bend right=30]{chapter}{in}{c}
```
