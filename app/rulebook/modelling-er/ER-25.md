+++
id = "ER-25"
title = "An entity type can depend on itself only by existence"
kind = "warning"
applies = ["weak relationship type", "weak entity type"]
fix = "Make it a normal relationship"
see = ["ER-26", "ER-27", "ER-28"]
+++
**Rule.** A weak relationship type between an entity type and itself (chapters within chapters) **must
not** be an identification dependency; it **may** be an existence dependency (**E**).

**What the program does.** A warning, *"'Chapter' depends on another 'Chapter' here, which can't be an
identification dependency: the key of each 'Chapter' would contain the key of the one above it, and
that one's, without end. Choose E (existence dependency), or make it a normal relationship"*, with the fix
*Make it a normal relationship*: it removes the weak mark and the dependency from the relationship type
and makes its lines single. The entity type stays weak; if it no longer depends on anything, unmark it
too (ER-19 then reminds of it).

- It is given for **Id**, and also for a relationship marked only weak, without saying E or Id: that
  counts as an identification dependency.
- With **E**, the other rules about it apply: ER-26 to ER-28.

**Why.** An identification dependency puts the owner's key into the dependent's key. If the owner is of
the same type, its key contains the key of the one above it, and so on without end: no key could ever be
written down. An existence dependency only says that a chapter can't exist without the one it is in;
that can be enforced (deleting a chapter deletes those within it).

**Examples.**

```erd violates ER-25
\entity[weak]{chapter}(0,0){Chapter}
\attributes[anchor=west]{chapter}{*Title}
\relationship[dependency=Id]{in}(5,0){in}
\link[role=part, double, bend left=30]{chapter}{in}{cn}
\link[role=whole, double, bend right=30]{chapter}{in}{c}
```

```erd violates ER-25
\entity[weak]{chapter}(0,0){Chapter}
\attributes[anchor=west]{chapter}{*Title}
\relationship[weak]{in}(5,0){in}
\link[role=part, double, bend left=30]{chapter}{in}{cn}
\link[role=whole, double, bend right=30]{chapter}{in}{c}
```

```erd follows
\entity[weak]{chapter}(0,0){Chapter}
\attributes[anchor=west]{chapter}{*Title}
\relationship[dependency=E]{in}(5,0){in}
\link[role=part, double, bend left=30]{chapter}{in}{cn}
\link[role=whole, double, bend right=30]{chapter}{in}{c}
```

```erd follows
\entity{chapter}(0,0){Chapter}
\attributes[anchor=west]{chapter}{*Title}
\relationship{in}(5,0){in}
\link[role=part, bend left=30]{chapter}{in}{cn}
\link[role=whole, bend right=30]{chapter}{in}{c}
```
