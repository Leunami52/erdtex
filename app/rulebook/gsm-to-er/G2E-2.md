title = "The key of a converted entity type"
kind = "conversion"
applies = ["entity type", "attribute"]
see = ["G2E-1", "G2E-3", "ER-1"]

**Rule.** GSM has no keys, so each entity type made from an abstract type, an aggregation or a grouping
**becomes** keyed by the first of its attributes that names an identifier, or, if none does, by an added
attribute *‹Name› ID*.

**Conditions.**

- An attribute names an identifier if the line's label contains the word *Id*, *Key* or anything with
  *identif…*, or the attribute's name contains the word *Id* or *Key*, or ends in *Id*, *No* or *Nr* right
  after a small letter (*orderNo*), or is just *Id*, *No* or *Nr*. Letter case doesn't matter.
- Derived, multi-valued and composite attributes are never chosen.
- The added key comes first in the list: *Room ID* for *Room*.
- Subtypes get no key: they inherit their supertype's (G2E-3).
- An entity type made from a representable type (G2E-5) has the key *Name*.
- The conversion's report lists, for each entity type, which key it has or that one was added.

**Choices.** *Add an ID key where no identifier is found* in the conversion dialog (on by default). Off,
such an entity type has no key, and the report says so (ER-1 then hints at it).

**Why.** Every entity type needs a key to tell its entities apart, and the relational schema needs it as
primary key. An attribute that already names an identifier is the natural one; otherwise a surrogate key
keeps the result complete.

**Examples.**

```gsmd converts
\abstract{order}(0,0){Order}
\representable{no}(4,1){orderNo}
\representable{date}(4,-1){Date}
\attribute{order}{no}{has}
\attribute{order}{date}{placed on}
```

```erd result
\entity{order}(0,0){Order}
\attributes{order}{*orderNo, placed on}
```

```gsmd converts
\abstract{room}(0,0){Room}
\representable{size}(4,0){Size}
\attribute{room}{size}{has size}
```

```erd result
\entity{room}(0,0){Room}
\attributes{room}{*Room ID, Size}
```

```gsmd converts keys=false
\abstract{room}(0,0){Room}
\representable{size}(4,0){Size}
\attribute{room}{size}{has size}
```

```erd result
\entity{room}(0,0){Room}
\attributes{room}{Size}
```
