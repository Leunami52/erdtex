+++
id = "G2E-12"
title = "An attribute of several objects becomes an attribute of their relationship"
kind = "conversion"
applies = ["attribute line", "junction point", "relationship type"]
see = ["G2E-9"]
+++
**Rule.** An attribute line to a representable type that starts at a junction point joined by plain lines
to two or more object types **becomes** an attribute of the relationship between those entity types; if
there is none, a relationship *has* (`cn` at each) is made for it.

**Conditions.**

- An existing relationship counts if it connects exactly those entity types.
- The plain lines to the junction point are used up by this; the report names the attribute and its
  relationship.

**Why.** A value that depends on a combination of objects (the year a person started at a company)
belongs to neither object alone: it describes their relationship.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\abstract{company}(8,0){Company}
\point{p}(4,0)
\link{person}{p}
\link{p}{company}
\representable{year}(4,3){Year}
\attribute{p}{year}{since}
```

```erd result
\entity{person}(0,0){Person}
\attributes[anchor=west]{person}{*Person ID}
\relationship{has}(5.2,0){has}
\attributes[anchor=north]{has}{Year}
\entity{company}(10.4,0){Company}
\attributes{company}{*Company ID}
\link{person}{has}{cn}
\link{has}{company}{cn}
```
