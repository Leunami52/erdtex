+++
id = "G2E-1"
title = "An abstract type becomes an entity type, its attributes attributes"
kind = "conversion"
applies = ["abstract type", "representable type", "attribute line", "entity type"]
see = ["G2E-2", "G2E-3", "G2E-4"]
+++
**Rule.** Each abstract type **becomes** an entity type of the same name (and position), and each
single-valued attribute line from it to a representable type **becomes** one of its attributes.

**Conditions.**

- The attribute is named after the representable type it leads to, or after the line's label instead
  where the type is generic (*string*, *text*, *number*, *integer*, *real*, *decimal*, *boolean*, *date*,
  *time*, *datetime*, *amount*, *value*, *count* …) or several lines lead to it.
- A label in square brackets marks a derived attribute (G2E-11).
- The key is chosen by G2E-2.
- Attribute lines to object types, multi-valued lines and lines to aggregations or groupings have rules
  of their own (G2E-4 to G2E-10).

**Choices.** *Attribute names* in the conversion dialog: *Type name, or edge label for generic types*
(the default, as above), *Type name* or *Edge label* always.

**Why.** An abstract type stands for objects of their own, as an entity type does; the representable
types it is linked to are the values that describe those objects, as attributes do.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\representable{pid}(4,1){Person Id}
\representable{name}(4,-1){Name}
\attribute{person}{pid}{has Id}
\attribute{person}{name}{has name}
```

```erd result
\entity{person}(0,0){Person}
\attributes{person}{*Person Id, Name}
```

```gsmd converts names=edge
\abstract{person}(0,0){Person}
\representable{pid}(4,1){Person Id}
\representable{name}(4,-1){Name}
\attribute{person}{pid}{has Id}
\attribute{person}{name}{has name}
```

```erd result
\entity{person}(0,0){Person}
\attributes{person}{*has Id, has name}
```

```gsmd converts
\abstract{person}(0,0){Person}
\representable{text}(4,0){Text}
\attribute[bend left=25]{person}{text}{first name}
\attribute[bend right=25]{person}{text}{last name}
```

```erd result
\entity{person}(0,0){Person}
\attributes{person}{*Person ID, first name, last name}
```
