**Rule.** Parts of a GSM diagram without an ER meaning **become** nothing; the conversion's report lists
each of them.

**Conditions.**

- A plain line (not to a junction point used by G2E-12): *"the plain link A – B has no GSM meaning and
  was not converted"*.
- An attribute line from a type that has no entity type (a grouping, or an aggregation that became a
  relationship or a composite attribute) or to a type that can't be an attribute: *"the attribute x of A
  was not converted"*.
- A grouping without a component: *"grouping x has no member type and was not converted"*.
- Labels on IS-A edges (G2E-3).
- Notes, subdomains and the helper grid aren't carried over.

**Why.** The ER diagram should say only what the GSM diagram said; whatever has no counterpart is listed
rather than guessed at, so that nothing is lost silently.

**Examples.**

```gsmd converts
\abstract{person}(0,0){Person}
\abstract{company}(8,0){Company}
\link{person}{company}
```

```erd result
\entity{person}(0,0){Person}
\attributes{person}{*Person ID}
\entity{company}(8,0){Company}
\attributes{company}{*Company ID}
```
