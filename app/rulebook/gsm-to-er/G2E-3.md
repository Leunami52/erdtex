+++
id = "G2E-3"
title = "A subtype becomes an entity type below an IS_A"
kind = "conversion"
applies = ["subtype", "generalization", "specialization", "IS_A", "entity type"]
see = ["G2E-2", "ER-33"]
+++
**Rule.** Each subtype **becomes** an entity type; the generalization edges to one supertype **become**
one IS_A with the letters **cd** (complete, disjoint), the specialization edges to one supertype one IS_A
with **io** (incomplete, overlapping).

**Conditions.**

- A supertype with both generalization and specialization edges gets two IS_As, one of each kind.
- The subtypes' attributes become theirs, as for abstract types (G2E-1); they get no key of their own,
  since they inherit the supertype's (G2E-2).
- A label on an IS-A edge can't be expressed in ER: the report says so, and it is left out.

**Why.** A generalization says its subtypes are disjoint and together make up the supertype; a
specialization describes roles that may overlap and needn't cover every object. The IS_A's letters say
the same in ER.

**Examples.**

```gsmd converts
\abstract{vehicle}(0,0){Vehicle}
\subtype{car}(-2,-3){Car}
\subtype{boat}(2,-3){Boat}
\generalization{car}{vehicle}
\generalization{boat}{vehicle}
```

```erd result
\entity{vehicle}(0,0){Vehicle}
\attributes{vehicle}{*Vehicle ID}
\isa{isa_vehicle}(0,-1.8){vehicle}{cd}
\entity{car}(-2.6,-3.9){Car}
\entity{boat}(2.6,-3.9){Boat}
\link{car}{isa_vehicle}
\link{boat}{isa_vehicle}
```

```gsmd converts
\abstract{person}(0,0){Person}
\representable{pn}(4,0){PName}
\attribute{person}{pn}{has name}
\subtype{student}(-2,-3){Student}
\representable{field}(2,-5){Field}
\attribute{student}{field}{studies}
\subtype{emp}(2,-3){Employee}
\specialization{student}{person}
\specialization{emp}{person}
```

```erd result
\entity{person}(0,0){Person}
\attributes{person}{*Person ID, PName}
\isa{isa_person}(0,-1.8){person}{io}
\entity{student}(-2.6,-3.9){Student}
\attributes[anchor=west]{student}{Field}
\entity{emp}(2.6,-3.9){Employee}
\link{student}{isa_person}
\link{emp}{isa_person}
```
